# Review Architecture

Read the project's architecture guidance and the requested scope. Inspect representative implementation paths and tests; treat the documented design as a target, not proof of current behavior. Map responsibility and dependency direction, then report actionable gaps with file and line evidence, consequences, and practical corrections. Distinguish demonstrated defects from design gaps. State coverage limits and checks performed; propose staged changes when useful. Do not edit code or save a report unless requested. Use an architecture reviewer agent if available and delegation is authorized; otherwise review directly. This is an on-demand review, not a routine gate.

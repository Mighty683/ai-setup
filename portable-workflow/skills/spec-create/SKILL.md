# Spec Create

Follow the repository's specification conventions. Inspect existing guidance and relevant code, distinguishing enduring decisions from implementation details. Edit the existing topic when possible. Write concise rules and consequential ownership or boundary constraints; keep task history and implementation inventories out. Preserve requirements and surface conflicts instead of silently weakening them. Check links and the diff.

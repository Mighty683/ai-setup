# Task Ux

Read the task, story, relevant product context and user research; inspect the affected flow. Record evidence and unresolved user needs, a journey from starting state through actions to outcomes, recovery paths, and affected screens. Label simulated research and untested assumptions. Include questions only when their answers affect the flow; missing screenshot visibility does not prove a feature is absent. Follow the project's documentation conventions.

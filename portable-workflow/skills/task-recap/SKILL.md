# Task Recap

Compare the task documents with the implementation and available verification. Reconcile superseded proposals with the delivered design and keep only consequential decisions, reasons and lasting tradeoffs in the architecture record. Preserve unresolved work and set status from evidence; a recap does not prove completion. Update the task index if required by project conventions. Keep execution diaries, command transcripts, and agent handoffs out of enduring records.

# Interview Create

Follow the project's research conventions and preserve existing evidence and provenance. Use one report per persona and an index for shared method, date, limitations, and links when this structure fits the project. Assess personas independently. Label simulated reviews and predictions; never invent participant observations, quotes, or measurements. Separate interpretation from original feedback. When reorganizing, preserve findings and repair links.
